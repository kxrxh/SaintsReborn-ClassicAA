# Classic AA for Saints Reborn

Native SMAA 1x High. Smoother edges, original colors and lighting.

**[Download the Windows installer](https://github.com/kxrxh/SaintsReborn-ClassicAA/releases/latest)**

Requires a working **Saints Reborn source/build installation** and **PowerShell 7**.

## Install

1. Save and close the game.
2. Open the installer, select your Saints Reborn folder and click **Install**.
3. Enable **Classic AA** in Whompay's Mod Loader.
4. Select **SMAA High** in **Options → Display → Anti-aliasing**.

Your choice is saved. Menus are skipped by default.

Run the installer again to **update**, **uninstall** or **recover** an interrupted installation. Keep the rollback backup it creates.
